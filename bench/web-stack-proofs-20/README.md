Eight source recipes frozen before timing: four captured-control reductions, two same-source ordered zip/folds, and two independent-array zip/postmap consumers. This is a bounded corpus of callback instantiations, not a general language ranking.

The four gate recipes have enabled and disabled modes in each small/full distribution and size 32/4096/65536 (48 cells). The other four recipes each have six cells (24 cells). There are 128 complete correctness/timed frames. Empty, full-width, zero-divisor, equal parameters and unequal/empty paired-array edges are checked. Independent full-width ys is shorter by floor(N/8); xs and ys are distinct immutable donor arrays. All thresholds and scalar modes are preset independently of performance measurements. Branch counts are retained; not every inner branch is required to occur in every timed cell.

JS/Rust original controls preserve materialized source stages and ordered right folds. Expert controls already hoist captured runtime flags, remove disabled compute loops, fuse zip consumers, and reuse vector destination scratch. JS count accumulates in an exactly representable physical array-length Number and converts once to BigInt. Rust count is U64; Wasm returns two U32 lanes. Native scalar Rust returns the same shared algorithm helper directly through BenchResult.scalar, avoiding Wasm output stores/reloads. Strong controls can legitimately beat checked Ink.

Captured web calls include copies of every declared list even for disabled gates; Wasm input copies, output conversion and observation are timed. Borrowed JS is separately labelled. Native resident and snapshot modes are separate; native comparison is emitted C/Clang versus Rust under their recorded toolchains. Actual GPU counter/readback coverage is validated independently for schema1 and schema2, and CPU fallback is never called GPU timing. Same-store CPU and GPU policies may choose different checked programs; eligibility is distinct from measured profitability.

The independent vector consumer theorem is a fresh direct endpoint composed from existing identity-map and prior independent-zip mathematics. The two ordered reductions use one source list, not independent-array folds. No runtime caller checks or production optimization changes are introduced by this harness. Main source/proof/fixture preparation and all timings belong to the parent lane.
