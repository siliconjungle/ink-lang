# Round22 guarded and indexed consumer benchmark

Twelve exact author U32 recipes comprise six pointwise guard-merger scalar consumers and six indexed mapped self-zip vector consumers. All source signatures are `(xs:List<u32>,seed:u32,k:u32)`; the shared Rust/native adapter's unused `ys` slot is empty and not captured. Primary and alternate callback instantiations are preset holdouts, not an external corpus.

Literal JS and Rust preserve repeated source guards, source map arrays, indexed operand arrays and zip result arrays. Experts already merge guards or fuse indexed transforms into one input pass. Each selected mapped operand is computed once. Primary same-choice expert can reuse the guard quotient for its selected second contribution when the divisor is nonzero; the zero-divisor fallback remains exact. Held-out experts also reuse the wrapped x*k product needed by the guard when a selected contribution uses it. Vector experts reuse output destinations. A shared Rust scalar algorithm serves native direct return and the Wasm output-lane adapter.

Immutable donor arrays retain their exact U32 words. Scalar sizes32/4096/65536 use preset divisors2/3/5 and small cutoffs512/256/128 or full-width cutoffs0x40000001/0x20000001/0x10000001. Parameters vary with size; no size-only scaling conclusion is justified. Indexed tasks retain21's primary/alternate presets. Profiles report top guards, selected inner callback gates, indexed position periods and comparisons of actual mapped operands separately. Some inner or combine gates can be one-sided. Empty/singleton/extrema, zero divisors, equal parameters and index-period edges are correctness fixtures.

Nine shuffled rounds, two warmups,15ms target and seed20261031 are fixed before performance runs. Captured web calls include declared input snapshots and result consumption; borrowed JS and native resident calls are separate. Native C/Clang versus Rust toolchain differences remain a limit, and native allocation metrics are not inferred from web snapshots. ActualGPU timing includes upload/dispatch/readback and result consumption, with actual manifest eligibility and counters. Unsupported paths remain CPU fallbacks rather than GPU samples; no same-GPU gain follows from eligibility alone.

`generate.py` constructs exact staged original and strong expert controls. `fixtures.py` checks source operation association against independently expressed wrapped mathematical goldens. `preflight.py` checks every complete fixture output against both JS controls and unchanged inputs before any compiler builds or timings. Root owns compilation, publication, timing and independent saved-result audits. No runtime caller checks or optimizer wrappers are introduced.
