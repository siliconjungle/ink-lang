# Batch 25: accepted repair pipelines and backend regression references

Nine natural single-list `(xs, seed, k)` recipes form a backend/host × proof-catalogue factorial. Five new consumers cover variable-length accepted repair, exact ordered accepted checksums, and a wrapping accepted total. Four references cover legacy first-match primary/alternate, the existing compute transformed-head bridge, and a direct indexed vector/GPU kernel. The backend factor includes C lowering, Wasm export configuration and the CPU host bridge; it does not imply an isolated compiler-language comparison.

The archived demand facade compiles the fair-prior and checked cores once each; a separately pinned new facade compiles those same cores. No backend-dependent replanning is allowed. Original eager JS/Rust stages are validation-only. Strong experts fuse predicate/map, hoist legal invariant cutoffs, reuse vector output storage, preserve right-fold order and accumulator-dependent branching for checksums, and early-exit the lookup references. Native Rust returns scalar values directly through the common boundary; no avoidable output-word stores are inserted.

The fixed corpus has 207 complete frames and 72 timed cells: 32/65536 elements, small/full distributions, fixed per-distribution captures across sizes; 4096 is correctness-only. The three lookup references cover first/interior/last/absent matches. Other recipes retain donor words without selective timing-informed alteration. Empty, singleton, extrema, zero divisor/factor, equal captures, overflow and repeated-default frames are validated. Actual predicate and accumulator branches are recorded, without claiming every branch is balanced. Donor fixture bytes are hardlinked immutably.

Nine shuffled rounds, two recorded warmups and 15 ms targets are preset. Native uses adaptive calibration with zero-clock trials retained and escalated; all measured phases must be positive. Three common native prewarm calls precede timing and are distinct from recorded warmups. Full web calls include captures, Wasm ingress, result conversion and checksum consumption. Synchronous borrowed JS is a separate leaf boundary without promises or copies; native resident and snapshot modes are separately reported. Constant overhead can dominate tiny/O(1) consumers.

GPU representatives are deduplicated only by exact emitted ABI/host/device/WGSL bytes. All fixture outputs and actual requests, including empty inputs, are validated. Counters distinguish schema1 and schema2, actual GPU from CPU fallback, and new proof consumers from references. Variable filtered output vectors currently need CPU fallback; accepted total eligibility is determined by the frozen selected core/manifest, not the mathematical theorem. Existing U32 borrowing is a reference; new Bool borrowing has separate backend correctness evidence, not a timed Bool cohort.

This is a bounded set of callback instantiations on one machine. It does not establish broad superiority over optimized JavaScript, Rust or GPU execution. No caller-validation or runtime proof optimizer is added. Historical archives remain unchanged.
