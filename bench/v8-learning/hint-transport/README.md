replay the same references without allocating expanded vectors. Legacy arrays
keep their existing bytes and direct propagation loop. No circuit/source meaning,
theorem rule, semantic/circuit/RUP work budget or object byte limit changes.

witnesses with ordinary exhaustive Cases. The full U64 self-quotient law shrinks

admission under the existing 16 MB object limit. All 337 previous integer proof
identities stay unchanged; 338 of 340 proposals now admit. U64 self remainder and
zero-numerator remainder remain unadmitted. Strict repeated operands execute and
exceptional defaults remain lazy. Four authentic, rehashed corruptions reject.

Root and exact standalone core suites each pass all 470 tests. The related
