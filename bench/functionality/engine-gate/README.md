Frozen source, JavaScript baseline and complete-call adapters for the mandatory
[JavaScript engine rollout gate](../../../docs/javascript-engine-gate.md).

The baseline producer and exact SHA256 bindings are in `config.json`. Compare a
freshly built compiler with `tools/engine-gate/gate.mjs`; do not regenerate the
baseline as part of that comparison. `source.ink` is a public, independently
authored scalar-record/forecast fixture. Private application inputs remain in
their private audit workspace.

`selected-receipt.json` retains the selected local three-process-per-engine run.
The candidate generated byte-identically to `baseline.mjs`; the repeated
measurement is an A/A admission control for this gate, not a speedup claim.
Future CI executions emit their own candidate and receipt as Actions artifacts.
