# Real software automatic delivery

This epoch selects upstream function bodies before testing catalogue applicability.
Development: D3 min/cumsum. Held out: D3 max, Earcut signed area, Three.js bounds,
gl-matrix dot/squared length, CodeMirror text length. All choices, unsupported
ports and semantic restrictions are retained. Package/function selection is human
and domain driven; this is not a random software-population sample. D3 min/max
are related siblings, so their split is weaker than the other package holdouts.

Ports preserve upstream loops and scalar evaluation order. Typed interfaces
normalise empty extrema/bounds explicitly. Numeric fixtures are bounded so Ink's
wrapping words and f32 results agree exactly with upstream JavaScript Numbers.
The vector kernels use a batch wrapper around scalar upstream functions. Reports
must disclose wrappers, conversion and complete output consumption. CodeMirror's
original UTF-16 string-length kernel is an explicit capability test, not a
precomputed-length replacement. Unsupported source stays in the coverage count.

Real input seeds come from pinned upstream source line lengths, Three.js unit-test
vectors and an Earcut polygon fixture. Original seed sizes and controlled stress
repetitions/empty/reversal distributions remain distinct. Stress copies are not
additional independently observed production datasets.

Before freezing the epoch, cold-build profiling identifies generic catalogue
costs. Isolated diagnostic timings do not imply equal full-build speedups. The
compiler binary and every planning/producer resource are then frozen; quick and
balanced are existing named policies, evaluated without changing defaults.

Knowledge growth uses four reusable lazy-choice schemes from development control
flow. Each has an ordinary Cases/Normalize proof, checked in concrete scalar/list
carriers before publication. No law is authored or adjusted from held-out timings.
Sources reach ordinary automatic compilation with no supplied workload, manual
selection or forced packet. A literal unoptimised emission is a separate baseline;
pinned older/newer snapshots isolate database growth within the frozen epoch.

Run `python3 bench/real-software-delivery/run.py freeze`, then `build`, `reference`,
and the Node validation/timing driver. Raw artifacts, all losses, complete runtime,
coarse process-memory costs, compile phases and paired fixed-corpus uncertainty
must be retained. The protocol hashes code, sources, fixtures and snapshot pins;
changing any of those ends the epoch.

The first compact-tree survey was halted after complete recorded builds when a
separate development profile identified tens of thousands of Merkle-node reads
and writes. `transport-protocol.json` registers the layout revision before any
held-out execution timings: repack identical logical IDs using the already
supported 64-entry leaves. Run `repack.py`, then `run.py transport-build`; original
compact rows remain a partial cost survey. Physical layout and theorem growth
are separate factors, and no compiler code changes during this revision.

Repacking reuses only discovery summaries. Drop copied observation, membership
and snapshot-cache rows before refreshing the exact pin; copying cost summaries
without their measurement files fails closed. The first such setup failure is
preserved in the report and excluded from successful-build medians explicitly.

To reproduce, extract `compiler-macos.tar.gz` into
`build/real-software-delivery/compiler/`, or set `INK_REAL_COMPILER` to a binary
with the protocol's exact hash. The compiler is the prior integrated, pre-JSON
snapshot; newer distribution source and backend pins do not describe its timings.
Code/resource inventories bind the epoch separately. Final current-main
integration is validated as a separate epoch, without transferring old timings.

For frozen replay, use a separate checkout with planner `40f57297` and knowledge
`3197ec0b`, then apply `frozen-knowledge-code.patch` to the latter. This reconstructs
measured knowledge code commit `11218cb3` without changing the current checkout.
Verify every resource against `machinery-sha256.json`, restore the original
snapshot recorded in the protocol, and use the archived compiler. The final
current-main pins and rebuilt binary have separate validation records.
