Adaptive39 prepares one already checked composed padded indexed-pair pipeline using frozen compiler `dc9e2523`. It does not change the language, proof DB, planner or production defaults.

The fixed matrix uses training sizes32/65536 and heldout sizes2048/4096. Each size has low/high word values and empty/long irrelevant suffixes. Captured-owned and resident-input-owned-readback are separate boundaries:16 training cells and16 heldout cells. Four additional edge fixtures are untimed only.

Captured calibration invokes the real `backend:auto` host paths. Extreme saved profile prices force each eligible CPU/JavaScript/GPU candidate. In particular JavaScript still pays automatic transport packing/unpacking and host selection; explicit JavaScript's shortcut is a separate control. Direct CPU/GPU calls use their existing host capture; the direct JavaScript control copies both input lists. Resident calibration uses an external selector with preparedCPU+Array.from, captured JavaScript snapshots, and actual preparedGPU full owned readback. Inputs/setup/upload are outside resident timers; all returned output words and owned-output conversion are inside every timer.

A first selector miss is measured once per heldout fixture/boundary after explicit backend startup warmup. Its timer includes context, selection, Promise scheduling, execution and the same full-output checksum consumer; verification is outside. Cached automatic calls, staticCPU, forced automatic paths and direct controls are measured in three paired rounds. The firstmiss is not an isolated cache-only measurement or a replicated confidence interval.
