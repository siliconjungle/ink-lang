
`action_values.py` emits three general carrier entries alongside a complete
source image. Values use flat postorder nodes with balanced transport, binary
exact-integer magnitudes and full nominal/type correspondence. It needs no
aggregate certificate. Its independent `encode` function agrees with Ink's
bounded codec on supported action values. Admission checks exact definitions and
source data; these entries do not certify an interpreter or a replacement.
See ink-lang `docs/action-values.md` for the format and replay commands.

`representations.py --cache-query NAME --preserve-cache` proposes source-bound
cache retention after aborted changes/host failure and unrelated committed
writes. `cache_maintenance.py` generates universal branch equations using the
existing equality rules. Dependency analysis is an untrusted authoring heuristic;
only checking the exact source-bound equations grants selection authority.
See `research/cache-maintenance` for frozen requests and replay instructions.

`representations.py --compact-queries` avoids carrying a second copy of table
roots through query execution. Cached query replies reconstruct their next tuple
directly; ordinary queries carry only the cached value where needed. Every
observation/preservation equation is still checked. See `research/compact-queries`
for frozen requests, migration, comparable cost observations and executor limits.

Engine40 target-work diagnostics are optional external acquisition tools:
`target_work40_js.mjs` and `target_work40_c.py` instrument literal emitted sites;
`target_work40_prepare_js.py` binds the frozen suite and replays its exact captured
JavaScript boundary untimed. Missing C/Rust/Wasm/GPU boundary work is not supplied
from JavaScript. `web_cost40.py` freezes separately fitted target/host/boundary/
emitter prices and predictions before heldout evaluation. It uses only explicitly
supplied training labels and leaves defaults unchanged.

`import_target_work40.py` prepares canonical diagnostic definitions, price
JSON and measured observations without publishing. Namespaces
`ink-target-work-measurement-v1` and `ink-target-work-prices-v1` carry no theorem
or application authority. Exact fractional samples and model JSON remain bound;
the observation index retains its existing rounded integer timing format and
unknown peak memory. The publisher must retain ordinary snapshot-bound candidate
checking. Full contract and offline acquisition exclusions are documented in
`planner/docs-physical-features.md` in the distribution checkout.

Physical import optionally accepts `--context CONTEXT.json`. The general bound
publication context is embedded, with its exact content hash, in every measurement
and price entry and recorded as a diagnostic dependency. This carries acquisition
limitations, poor heldout outcomes and environmental contention alongside prices;
it cannot supply a theorem or application condition. Context source mutation is
rejected. Frozen model JSON, predictions and evaluation remain unchanged.
