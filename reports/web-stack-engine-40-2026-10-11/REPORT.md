# Engine40: composed storage, transport and emitted-work evidence

This pass broadens generic lowering and keeps algorithmic equivalence and measured selection outside the engine. Source is published directly to main in independently versioned target/runtime packages. Exact frozen compiler binaries and pins are recorded in candidate-source-receipt.json. No Ink syntax, caller checks, checker wrapper, trusted optimisation rule, task whitelist or default cost-policy change was added.

## What changed

The core exposes a separate private-storage reuse capability. The existing length-preserving placement capability remains length preserving; stable compaction cannot grant the larger producer permission to occupy a final-result-only destination. Fresh same-layout flat collections can be consumed by pure maps, indexed maps, scans and filters. Borrowed/shared receivers and callbacks capturing collections retain independent storage. C and JS compact private buffers in stable order. Rust traverses borrowed lexical lists without bulk cloning and consumes fresh vectors for in-place transformations, preserving eager stages and ordered right folds. Complete C concat now implements the existing primitive for supported carriers, including nested, string, arbitrary integer and record lists.

Runtime packs non-U32 words directly into typed transport buffers, decodes terminal arena outputs before reset without a terminal packed copy, and writes caller destinations directly. Cross-reset stage values retain necessary ownership copies. Adaptive automatic U32 JavaScript calls can consume their private captured transport inputs; explicit/static JS keeps its borrowed-input contract. Public packed results remain owned Arrays. GPU readback still copies mapped storage before unmap and omits the redundant subsequent header-stripping copy. Mixed generated hosts detect shader, graph and scalar GPU descriptors, use the emitted call/run API, and await disposal. These mechanisms are independent of workload names.

## Parity and authority

The final root gate checks 91 mixed requests plus 20 requests through an existing content-bound helper law on all five CPU paths. It executes 95 eligible native wgpu calls. Exact final-capacity C destinations run under ASan/UBSan; JS destination tails and subarray canaries are preserved. C and JS fixture gates each cover 357 outputs. Actual headed-browser parity records 612 checks and 150 GPU calls, including complete mixed snapshots, both packed/legacy host families, captured input lifetime, static borrowed JS, retained results and actual transfer/dispatch counters. The initial browser failures were harness key-order comparison, integer JSON normalization and a static-JS caller-lifetime violation; their attempts are preserved separately.

Conformance is evidence for the tested domain, not a universal proof of target emission. Existing WGSL numerical/resource contracts and explicit CPU fallback remain. The ordinary mathematical checker rechecks DB applications; content hashes, profiler traces, cost models and passing native tests do not establish semantic equality.

## Measurement protocol and scope

General40 freezes 12 tasks, 492 correctness frames and 288 timed cells. It includes maps, stable compaction, reductions, scans, stencils, ordered folds, gathers and incremental/recompute controls, crossing sizes, shapes and data distributions. Strong hand-written JS and separately compiled Rust native/Wasm controls are compared at matching ownership boundaries. Emitted Rust is compiled independently; C data is never relabelled as Rust. Resident device runs and complete GPU requests are separate, as are reused destinations and owned results. All result words enter the timed consumer.

The fit uses only affine/compaction/scan at sizes 64/8192 (48 cells); the other 240 cells are held out. Coefficients and all heldout predictions freeze before comparative heldout labels are opened. Previously measured Engine39 families are exploratory; four added families are disjoint from this fit. Five interleaved rounds do not remove environmental noise or establish statistical independence. Warm startup is not cold load latency. Raw results, failures, losses, exact bindings and reproduction commands are preserved.

## Provisional Node results

Complete C-Wasm vector calls improve by a geometric mean 1.602× versus the old compiler (214 faster, 0 slower, 38 uncertain cells); resident C-Wasm is 1.014×. Captured JS owned calls are 1.007× and emitted Rust-Wasm owned calls 0.988×. Eleven of twelve JS modules and eleven of twelve C kernels are byte-identical between compilers. This is predominantly host/transport improvement, not a demonstrated DB law or generally faster kernel. All 12 literal emitted Rust methods do change: borrowed lexical traversal and eligible intermediate Vec reuse reach the measured path. Both public Rust inputs still become owned Vec copies and the public result remains owned. No borrowed-input or Into Rust ABI is claimed.

Against the predeclared strong expert controls, candidate JS is 0.878×, complete C-Wasm 0.701× and emitted Rust-Wasm owned 0.944× on vector cohorts (>1 favors Ink). These separate ratios do not establish general superiority. All gain/loss cells and boundary-specific comparisons are retained in [NODE-PROVISIONAL.md](general/prepared-final/NODE-PROVISIONAL.md), [node-summary.json](general/prepared-final/node-summary.json), and [rust-method-attribution.json](general/prepared-final/rust-method-attribution.json). The ordinary run began with our lanes idle; external builds and another benchmark appeared later. It was completed without filtering or rerunning losses. The process snapshots require every speed conclusion to remain provisional.

## Fusion diagnosis and transport attribution

The matched [fusion diagnosis](fusion/RESULTS.md) preserves the full twenty-case historical inventory and distinguishes the eight Node cells remeasured here from the small, complete-call and browser cells reviewed earlier. Three fresh Node processes pass 768 validations and 6,912 ordinary samples. Four composed high-regime JS losses persist, while simple plain fusion improves. Large composed resident-Wasm losses reverse when both loop and SLP vectorizers are disabled. Native/Wasm LLVM optimized instruction sites differ; static sites are not dynamic work counts or a native runtime explanation.

Four separate V8 profiles locate substantial composed work in the system math library. All primaries reach TurboFan; checked code has fewer observed bailouts, and its bailout is an OSR transition. Extra checked deoptimizations therefore do not explain those cases. The profiles do not identify the particular math operation or its steady-state frequency. Two-pass scheduling and explicit U32 diagnostics vary by context, and byte-identical clones show JIT-context sensitivity. No source whitelist, global fusion/SIMD penalty or unproved representation rewrite was installed. Raw profiles and instrumented data are excluded from ordinary ratios.

The fixed-kernel [transport attribution](transport/ATTRIBUTION-RESULTS.md) passes 252 instrumented calls, 84 warmups, 112 actual GPU calls and 134 artifact bindings. It confirms the executed capture/decode paths and removal of the targeted terminal copies, with inclusive overlap handled explicitly. Most phase spans resolve to zero at the browser clock's approximately 0.1 ms increments, so the experiment does not quantify their latency or establish a speedup. GPU physical work is unchanged, and its asynchronous return interval does not isolate shader time. Every adverse result remains in the summary.
