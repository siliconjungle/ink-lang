# Controlled comparison and proof extension

The delta package first adds two universal theorems and an actual source maintenance candidate under the original compiler, SHA-256 `e4a7349ad8fd2cb941c761e36eb870324edc534e4733df04f93939284440badb`. `proof-extension.json` binds that binary to the original source hashes and the new certificate. The new library has 37 objects, up from 35. Executed audit deterministically reproduces all object bytes and the final source/evidence/certificate with the recorded original compiler. The generic logic, bit-proof checker and source-maintenance correspondence remain unchanged.

A separate native-lowering change borrows exact operands instead of cloning the cache and its input variables repeatedly. It preserves the arithmetic tree; operations return owned temporaries that BigInt can reuse. This is efficient primitive execution in the declared trusted Rust/BigInt/backend boundary. It installs no arithmetic theorem or algebraic rewriting rule in the compiler. The undo journal still retains its rollback copy, and returned cache values remain owned. Bounded emitted runtime source is byte-identical to the previous report.

The 1,008 samples cover exactly 18 cells × 8 variants × 7 repeats. Every trial shares the same separately compiled C timing driver and matched deterministic stream. The old cloned implementation is recompiled from the previous archived generated Rust, not silently generated by the new compiler. Borrowed/canonical versus borrowed/delta separates the expression choice from the copying change. Storage, arithmetic representation, speculative writes, query ABI and handwritten prevalidation differ as disclosed in REPORT.md.

`audit.json` verifies archived source/artifact/binary hashes, a complete sample matrix, identical observable signatures within each cell and independently recomputed geometric means. It replays exact emitted source/plans, 144 measured native streams, and 16,040 native oracle comparisons against the independent Python state model plus 4,010 reference outcomes. It never rebuilds the timed native artifacts during replay.

The full suite passes 63 tests (`tests.log`). All three candidate packages execute over signed 512-bit inputs, batches, rollback, tentative reads, filtered sums/counts, ordered events, rejected selection and future portable checkpoints. New rejection cases reverse the delta subtraction, substitute the wrong application proof and remove its new theorem after rehashing. Existing legacy large-constant/multiplication and bounded-modular native tests also pass after borrowing. Engineering tests do not formally verify the Rust kernel, bridge, table protocol or backend.

The compiler still owns the fixed row-pipeline recogniser, cache/transaction protocol and representation analysis. Complete database state-transition/representation evidence, multiplication and efficient large proof literals, automatic measured selection, recovery and the broader language remain pending. Bounded/Rust time is still 1.77× overall; these small-integer changes do not establish a new speed lead.

`sources/` preserves measured inputs; `verification-sources/` separately preserves final producer, audits and tests under the hashes in `verification.json`. Clang resolves native CPU to apple-m3 and Rust to apple-m4, as inspected under the recorded toolchains. The old compiler is retained locally at `build/cache-lowering-original/lang`; reproduction requires that recorded compiler or a reconstructed matching checkout. Its source identity can be recovered from the original commit `7002114e9f458c21b9a3ec78d1dd8f19e5ecee4e` and the archived previous report. Executed replay deliberately rejects a substituted compiler or changed native binaries.
