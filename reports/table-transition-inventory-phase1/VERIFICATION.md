# Verification and proof scope

All 70 tests pass. The exact test/tool/document sources and full test log are archived with SHA-256 identities. The independent mathematical oracle covers 24 eight-write histories through both trace evaluators (384 intermediate states), including duplicate keys, absent removal, signed contributions and keys differing only in their high word. Generic-induction tests reject scope, type, constructor and fixed-premise violations. Rehashed legitimate-but-wrong definitions cannot change source meaning. Existing reference/native suites execute the new evidence alongside older choices through aborts, tentative reads, events, checkpoints and commit exhaustion.

The universal theorem covers initialized keyed contribution-table writes and every recorded intermediate contribution state. It does not yet prove arbitrary source row projection, native map abstraction/enumeration, transaction errors/events/undo scheduling, native arithmetic/ownership or durability. Numeric/128-bit ID keys are represented; unsupported key domains retain scanning.

The executed audit checks source/artifact identities, all 756 samples across the complete 18-cell/six-variant/seven-repeat matrix, observed outcomes and summary ratios. It replays 108 original measured native streams without rebuilding timed binaries, repeats 12,030 independent native and 4,010 reference observations, reproduces both version-4 certificates, and checks exact emitted code/plans. Version-4 emitted benchmark runtime source is byte-identical to the prior version-3 source from the pinned original compiler. The source/checking authority changes, with no new runtime algorithm or speed claim.

Certificate checking medians are recorded in audit.json as fresh-process warm-filesystem timings, including CLI/process overhead on an interactive shared host. Neither those timings nor the constructor proofs establish global compiler/runtime optimality. Toolchains retain their actual CPU target differences (Clang apple-m3, Rust apple-m4). Raw samples and measured artifact identities are preserved.
