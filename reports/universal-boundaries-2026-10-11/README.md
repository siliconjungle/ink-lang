# Universal implementation boundaries

Ink now checks externally proposed early-exit, owned-buffer and definition-unfolding alternatives. Backends emit the general checked mechanisms. Shared ABI, native support, expression analysis and saved-model policy replace duplicated owners. Historical optimisation APIs and compatibility features are removed. General database representations compile to standalone state, with transaction semantics and portable checkpoint/restore migration; the generic interpreter and Session/executor adapters are removed.

[Validation and exact pins](validation.json) records the reconciled 3,460-entry snapshot, 36 new general laws, independent Git dependency checks, cross-target execution and state/install gates. Native/browser decision and frame fixtures run through ink-abi; full host tests retain native destination values and poisoned-memory ownership boundaries. F32 arithmetic uses an explicit V7 contract after differential tests exposed inconsistent NaN handling.

This is conformance evidence, not a proof of emitted code or a performance claim. Archived measurements remain tied to their historical revisions; historical compiler-dependent suites are not claimed green. See [the operation contracts and trust limits](../../docs/universal-optimisation.md).

The final reconciliation integrates the standalone-runtime retirement from current main. The receipt distinguishes earlier validation from the independently pinned lowering/runtime refresh and current compiled-state tests. [The earlier receipt](validation-before-retirement-reconciliation.json) is historical evidence only.
